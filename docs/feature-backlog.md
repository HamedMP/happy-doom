# Feature Backlog

## MVP

- Lens selection.
- Random character roll.
- Fixed timeline spine.
- Agent-generated structured events.
- SQLite life, event, choice, state, and feedback persistence.
- Epilogue and replay.

## Near Follow-ups

- Add a dedicated life-summary route with choice history.
- Add seeded character rolls for shareable runs.
- Add an agent skill that reads `docs/` and proposes one feature at a time.
- Add richer feedback labels beyond thumbs up/down.
- Add asset validation to ensure every referenced asset exists.
- Add prompt regression fixtures for each lens and timeline beat.

## Out of Scope For MVP

- Accounts.
- Persistence across devices.
- Multiplayer.
- Branching world endings.
- Runtime image generation.
- External database services.
